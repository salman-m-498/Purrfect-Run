Purrfect Run
====================

A physics-based skateboarding game where you control a cat performing tricks, dodging obstacles, and building combos on an endless procedurally-generated terrain.

Features
--------
- **Endless Level Generation**: Procedurally generated terrain with varied surfaces, gaps, and grind rails
- **Physics-Based Movement**: Realistic skateboard physics with speed-based terrain adhesion
- **Advanced Trick System**: Ollie, Kickflip, Heelflip, Backflip, Frontflip, Pop Shove-It, Tre Flip, Manual
- **Dodge System**: Lateral movement to avoid obstacles
- **Combo System**: Chain tricks together without landing for multiplied scores
- **Cross-Platform Support**: Desktop, WebGL, and Mobile (Touch)
- **Contextual Tutorial System**: Progressive gameplay-based tutorials
- **Dynamic Difficulty Scaling**: Wave-based enemy system
- **Multiple Game Modes**: Story and Endless modes

Desktop Controls
----------------
| Action | Input |
|--------|-------|
| Push | Left-Click |
| Jump/Ollie | Left-Click + Swipe Up |
| Kickflip | Swipe Right in Air |
| Heelflip | Swipe Left in Air |
| Backflip | Left-Click Swipe Down in Air |
| Frontflip | Swipe Up (airborne) |
| Pop Shove-It / Tre Flip | Right-Click |
| Manual | Left-Click + Swipe Down (grounded) |
| Dodge Left | Press A |
| Dodge Right | Press D |
| Pause | Press ESC |
| Reset Orientation | Press R |

Mobile / Touch Controls
-----------------------
| Action | Input |
|--------|-------|
| Push | Tap |
| Jump/Ollie | Swipe Up |
| Kickflip | Swipe Right in Air |
| Heelflip | Swipe Left in Air |
| Backflip | Swipe Down in Air |
| Frontflip | Swipe Up (airborne) |
| Pop Shove-It / Tre Flip | Double-Tap |
| Manual | Swipe Down (grounded) |
| Dodge | On-screen L/R buttons |

WebGL Build
-----------
- Full keyboard and mouse support (including right-click)
- Touch support on mobile browsers
- Automatic keyboard focus management

Game Systems
------------
- **Stamina System**: Manage energy while pushing, jumping, and tricking
- **Health/Shield System**: Take damage from enemies, collect shields for invulnerability
- **Score System**: Points for tricks, combos, perfect landings, and grinding
- **Wave Controller**: Progressive enemy difficulty in Story and Endless modes
- **Chest Rewards**: Collectible items for power-ups after completing waves
